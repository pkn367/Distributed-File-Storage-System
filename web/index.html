Concurrency demo

Concurrent upload test: every simulated client uploads its own random file at the same moment. Conflict test: 8 clients write different contents to the same file (conflict.txt) simultaneously; afterwards the page downloads it and checks it was written completely by one client and never mixed. Browsers allow about 6 parallel connections per site, so larger tests run in waves — open a second tab or use the command-line client for more simultaneous clients.
